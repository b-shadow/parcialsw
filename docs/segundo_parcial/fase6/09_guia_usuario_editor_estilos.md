# Guia del editor de estilos

1. Abra **Generacion** y seleccione proyecto y diagrama.
2. Pulse **Transformar UML** para obtener el manifiesto actualizado.
3. En **Estilo y previsualizacion Flutter**, elija claro u oscuro para inspeccionar.
4. Ajuste colores, tipografia, radios y variantes.
5. Seleccione modulo, pantalla, estado y viewport para revisar el resultado.
6. Corrija cualquier diagnostico rojo de contraste.
7. Use **Guardar preset** si desea conservar el borrador como variante reutilizable.
8. Pulse **Guardar estilo** para confirmar la revision compartida.
9. Ejecute preflight y genere el proyecto coordinado.

Aplicar un preset no guarda automaticamente. **Cancelar** restaura la ultima revision. Si otro colaborador guarda mientras existen cambios locales, el sistema conserva el borrador y solicita comparar o recargar; nunca combina paletas silenciosamente.
