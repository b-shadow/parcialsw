# Fase 9 - Generador Frontend Flutter

## Objetivo

Completar el generador de frontend Flutter de la plataforma CASE inteligente, integrado al pipeline UML -> modelo intermedio -> artefacto descargable.

## Documentos

- `01_arquitectura_generador_flutter.md`: arquitectura interna del generador.
- `02_reglas_transformacion_uml_flutter.md`: reglas de conversion desde UML hacia Dart/Flutter.
- `03_estructura_flutter_generada.md`: estructura del proyecto Flutter producido.
- `04_servicios_api_estado_navegacion.md`: servicios HTTP, estado, rutas y pantallas.
- `05_exportacion_versionado_artefactos.md`: ZIP, manifiesto, checksums y registro de artefactos.
- `06_integracion_fastapi_frontend.md`: integracion con FastAPI y React.
- `07_pruebas_generador_flutter.md`: validaciones ejecutadas.
- `08_resumen_fase9.md`: resumen de implementacion y decisiones.
- `09_acta_cierre_fase9.md`: cierre tecnico de la fase.
